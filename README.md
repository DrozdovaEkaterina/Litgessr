# LitGessr

Браузерная игра на русском языке. Угадайте произведение мировой литературы по иллюстрации от первого лица.

- Простой режим без ограничения времени, средний — 90 секунд, сложный — 30 секунд.
- В раунде одна попытка и два поля. Верный автор или название дают 40 монет, обе части — 100. Бонус за скорость линейно убывает от 50 монет до нуля за время раунда, в простом режиме — за 90 секунд.
- Если в отправленном ответе нет верной части, партия завершается и открывается главное меню.
- В игре 50 произведений. Сцена выбирается случайно среди ещё не показанных за текущий проход. Очередность сцен сохраняется при смене режима и обновлении страницы. После 50 сцен начинается новый проход.
- Победа дня засчитывается за пять разных произведений во всех режимах вместе по календарю браузера. После победы игра продолжает текущий проход.
- Ник, статистика и победы дня хранятся локально в браузере. При обновлении номер раунда начинается с единицы.

Для запуска откройте `index.html` в браузере или запустите `python3 -m http.server` из каталога проекта. Сборка и сервер приложений не требуются. GitHub Pages публикует корень ветки `main`.
