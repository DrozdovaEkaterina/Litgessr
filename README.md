# Litgessr

Браузерная игра на русском языке. Угадайте произведение мировой литературы по иллюстрации от первого лица.

- Простой режим без ограничения времени, средний — 90 секунд, сложный — 30 секунд.
- Одна попытка на раунд. Фамилия автора или название дают 40 монет, обе части — 100. Бонус за скорость линейно убывает от 50 монет до нуля за время раунда, в простом режиме — за 90 секунд.
- 15 сцен перемешиваются при каждом новом запуске игры. После последней сцены начинается новый проход. Победа дня засчитывается за пять разных произведений во всех режимах вместе по календарю браузера.
- Ник, статистика и победы дня хранятся локально в браузере. После обновления страницы следующая партия начинается с первого раунда.

Для запуска откройте `index.html` в браузере или запустите `python3 -m http.server` из каталога проекта. Сборка и сервер приложений не требуются. GitHub Pages публикует корень ветки `main`.
